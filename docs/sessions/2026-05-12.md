# Session: 2026-05-12

## 작업 내용

### DB 마이그레이션: Supabase → Neon
- Supabase 무료 티어가 직접 연결(`db.xxx.supabase.co`) IPv6 전용으로 변경되어 Java JDBC 연결 불가
- Neon Serverless PostgreSQL로 전환 (무료, IPv4 지원)
- `.env` 변수명 변경: `SUPABASE_HOST/PORT/USER/PASSWORD` → `NEON_JDBC_URL`, `NEON_USER`, `NEON_PASSWORD`
- `application.yaml` datasource를 host/port 분리 방식 → 단일 JDBC URL 방식으로 변경
- DB 연결 성공 확인: HikariPool 시작 완료, `admin_users` / `sensor_data` 테이블 자동 생성 확인

### Spring 프로필 분리
- `application.yaml` → 공통 설정만 (admin, serial, server.port)
- `application-local.yaml` → 개발: `ddl-auto: update`, `show-sql: true`
- `application-prod.yaml` → 운영: `ddl-auto: validate`, `show-sql: false`, thymeleaf 캐시 활성화
- `spring.profiles.active`는 yaml에서 제거 → IntelliJ Run Config Active profiles 필드에서 설정
- WAR 배포 시: `SPRING_PROFILES_ACTIVE=prod` 환경변수 또는 Tomcat `setenv.sh`에 설정
