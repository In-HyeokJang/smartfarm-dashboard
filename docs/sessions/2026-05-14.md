3. **명령 수신 로직 추가** : `Serial.readStringUntil('\n')` 으로 서버에서 오는 `PUMP_ON` / `PUMP_OFF` 수신 및 릴레이 제어
4. **전송 주기** : 5초 → 3초 (서버 시뮬레이션 주기와 동일하게 맞춤)

### USB 시리얼 통신 원리 파악
- Arduino → Spring Boot 통신은 HTTP/URL이 아닌 **USB 케이블 직결**
- Windows가 USB를 가상 COM 포트(COM3)로 인식
- jSerialComm이 COM3를 열어 Arduino 데이터 수신
- Arduino Uno는 WiFi 칩 없음 → 인터넷 연결 불가 → COM 포트만 사용
- ESP8266/ESP32 같은 WiFi 보드는 HTTP POST로 서버 직접 호출 가능 (이 프로젝트는 Uno)

### 펌프 ON/OFF 버튼 전체 흐름 파악
```
버튼 클릭
  → fetch('POST /api/pump/on') + CSRF 토큰
  → PumpController.pumpOn()
  → serialService.sendCommand("PUMP_ON")
  → COM3로 "PUMP_ON\n" 전송 (시뮬레이션 모드에서는 로그만 출력)
  → Arduino: Serial.readStringUntil('\n') → pumpOn() → 릴레이 ON → 펌프 작동
  → 3초 후 Arduino가 "SOIL:850,PUMP:ON" 전송
  → DB 저장 → SSE → 브라우저 배지 업데이트
```
- 시뮬레이션 모드에서는 버튼 눌러도 배지 변화 없음 (3초마다 랜덤 값이 계속 덮어씀)
